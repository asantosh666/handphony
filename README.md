# Handphony

A hands-first WebXR symphony — conduct a living orchestra with bare hands.
Built for the Meta VR Start Developer Competition 2026 (Entertainment track,
New Experience division).

Open https://asantosh666.github.io/handphony/ in the Quest browser, tap to
enter, raise your hand. Right-hand height plays a pentatonic melody, left-hand
height sets the chords, an open palm swells the strings, and a pinch captures
your phrase as a loop. You cannot play a wrong note.
